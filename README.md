
# PASSGUARD
### Password Security Analyzer

PASSGUARD is a web-based password security analyzer built using Python and Flask. It helps users evaluate password strength and generate secure random passwords.

## Features

- Password strength analysis
- Live password strength indicator
- Detection of common passwords
- Repeated character and pattern detection
- Personalized security recommendations
- Secure random password generator
- Customizable password length
- Copy generated password to clipboard
- Cybersecurity-inspired user interface

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

## Installation

1. Clone this repository:

   git clone YOUR_REPOSITORY_URL

2. Navigate to the project directory:

   cd password-checker

3. Install dependencies:

   pip install -r requirements.txt

4. Run the application:

   python app.py

5. Open the local address displayed in your terminal.

## Disclaimer

PASSGUARD provides educational password-strength estimates. It does not guarantee that a password is secure against every attack.
